# Cristallo BTS

Appli (PWA) de sciences physiques pour le BTS : cristallographie (multiplicité N, compacité, masse volumique), cristaux ioniques, atomes, ions et tableau périodique, avec les explications de chaque calcul.

## Mise en ligne sur GitHub Pages
1. Crée un dépôt (ex. `cristallo-bts`) et envoie **tout le contenu** de ce dossier à la racine du dépôt.
2. Va dans Settings → Pages, puis choisis Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. L'appli sera en ligne sur `https://<ton-pseudo>.github.io/cristallo-bts/`.
4. Sur le téléphone, ouvre le lien dans Chrome, puis menu ⋮ → « Installer l'application ».

Fonctionne hors ligne après la première ouverture.
